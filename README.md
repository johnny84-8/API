# 🌦️ Uyo Weather

A modern weather website providing real-time weather updates for Uyo, Akwa Ibom State, Nigeria.

##  Features

* 🌡️ Current temperature in Celsius
* ☁️ Live weather conditions
* 💧 Relative humidity
* 💨 Wind speed
* 🌡️ Feels-like temperature
* ☁️ Cloud cover
* 🔄 Refresh button to update weather data
* 📱 Responsive design for mobile and desktop

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* [Open-Meteo API](https://open-meteo.com/) for weather data

## 📍 Location

Uyo, Akwa Ibom State, Nigeria 🇳🇬

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser, or use the Live Server extension in VS Code.
3. Connect to the internet to load live weather data.
